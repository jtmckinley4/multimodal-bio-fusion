# Research paper library

Start with BioLangFusion and IsoFormer to understand the two central fusion approaches, then use the papers below to follow their models, measurements, and biological assumptions. The [literature review](<../docs/Literature Review - Biological Foundation Models.docx>) develops the cross-paper discussion; the [annotated bibliography](../docs/Annotated_Bibliography.docx) retains formal citation and annotation detail.

**Core** groups the original project readings and encoders named in the [research canvas](../docs/Research_Canvas.pptx). **Supporting** groups background, methods, and benchmarks used in the literature review. These categories describe project roles, not a ranking of scientific validity or a requirement to read everything in order.

## Versions and reuse

The 13 newly acquired PDFs are intact source copies with only their filenames changed for navigation. Their author, publication, source, version, and license links are recorded above. CC BY requires attribution and the license notice; CC BY-NC additionally restricts use to noncommercial purposes; CC BY-NC-ND additionally prohibits sharing adapted material. These paper licenses remain separate from any license applied to repository code or team writing. Preserve the notices inside each PDF and its attribution when sharing it.

The acquisition check on 5 October 2026 covered source identity, available version information, access, licensing, and PDF readability. It did not establish scientific correctness or constitute a full reading of each paper. Source-only entries identify the remaining access or permission limits without preventing readers from visiting the original publications.
